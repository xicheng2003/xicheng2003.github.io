喝了这么多，前天晚上。
&nbsp;
二十多年以来，这次可能喝的最多的一次。
&nbsp;
有情有缘，也很好了其实。即便没走到最后。
&nbsp;
但是敞开心扉这样子聊，我真的很开心很开心
&nbsp;
毕竟爱过，一起经历过，都有很多难忘的回忆
&nbsp;
这段感情不会忘记，从来没有这种想法
&nbsp;
不管发生什么都坦然接受一切，而不是想掩盖什么
&nbsp;
毕竟也是美好远大于遗憾，这是内心珍藏的一份独家记忆
&nbsp;
看着你喝醉，说不心疼肯定是假的
&nbsp;
想好好陪陪你，但是我不能当老好人
&nbsp;
我总不能悲悯一切，总得把握好尺度
&nbsp;
看到你内心的痛苦，又想到自己的曾经
&nbsp;
像是苦行僧般走过这一切之后，
&nbsp;
感觉曾经没有那么重要
&nbsp;
因为来时的路不可言说
&nbsp;
说出来意义就变了
&nbsp;
所以呢，我理解你的痛苦
&nbsp;
但我又不能说完全理解你 而且事实也确实如此
&nbsp;
毕竟我是始作俑者 可不能以上帝视角看待这一切
&nbsp;
否则显得我很自恋和狂妄
&nbsp;
于是乎
&nbsp;
陪伴和安慰是我可以给到的
&nbsp;
我用心感受这一切
&nbsp;
体会这一切
&nbsp;
想喝就喝吧
&nbsp;
喝完一升以后
&nbsp;
我没想到你还会喝两升
&nbsp;
当然我也心软
&nbsp;
答应你了
&nbsp;
毕竟这种情况很少见吧
&nbsp;
既然如此无所谓了
&nbsp;
我喝到后面面红耳赤
&nbsp;
不敢喝了
&nbsp;
因为我想着不能醉
&nbsp;
我还想着要把你送回宿舍
&nbsp;
还好我后来做到了
&nbsp;
你喝醉了
&nbsp;
迷迷糊糊的样子其实很可爱
&nbsp;
我差一点心就软了
&nbsp;
你小小声地说了一堆 很认真地在说
&nbsp;
心里想说的都说出来吧
&nbsp;
我听不太清楚就凑近一点
&nbsp;
喝完了我就一起扶着你回去
&nbsp;
但其实没喝完，因为我不想让你再喝了
&nbsp;
还是担心你，喝成这样应该也可以浇愁了
&nbsp;
你搂着我 躺在我旁边 靠在我肩膀上
&nbsp;
在车上一句话都没说
&nbsp;
但是又感觉
&nbsp;
什么都对我说了
